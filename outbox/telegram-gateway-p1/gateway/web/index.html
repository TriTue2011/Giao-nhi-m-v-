Telegram Gateway

Trang quản lý nội bộ, chỉ dùng trong LAN. Đăng nhập tài khoản phụ Telegram (OTP/2FA/QR) chỉ thực hiện ở đây — không qua API của Home Assistant.

Trạng thái P1+P2: đăng nhập thật qua TDLib (OTP → 2FA nếu server yêu cầu → QR tùy chọn), gửi tin/media/voice thật qua MTProto, state machine gọi + glue TDLib→NTgCalls + TTS vào cuộc gọi + mic HA theo khối đã có. Định dạng PCM gọi riêng tư vẫn chờ T1 xác minh (tiền lệ group call s16le 48 kHz, chưa phải kết luận cho gọi riêng tư). Cuộc gọi thật với tài khoản phụ là bước T1, chưa chạy ở đây.

Đăng nhập tài khoản phụ

  1. Nhập số điện thoại → nhận login_id (gọi POST /ui/api/accounts kèm Bearer token).
  2. Nhập mã OTP (5–6 chữ số) → POST /ui/api/accounts/{login_id}/code. Nếu server yêu cầu 2FA thì nhập tiếp mật khẩu → POST /ui/api/accounts/{login_id}/password.
  3. Hoặc đăng nhập bằng QR: POST /ui/api/accounts/qr → quét mã → POST /ui/api/accounts/{login_id}/qr-confirm.
  4. Sau 3 mã sai, login_id bị khóa 15 phút (chống flood). FLOOD_WAIT của Telegram được tôn trọng đúng số giây server trả.

Token gateway, mã OTP và mật khẩu 2FA không bao giờ hiện trong log hay phản hồi của gateway.

Cảnh báo kiến trúc

Một tài khoản MTProto không chạy cùng lúc cả module web2api telegram-user lẫn gateway Docker này (tranh session/updates). Lúc triển khai: dùng 2 tài khoản phụ riêng (mỗi đường một tài khoản), hoặc chỉ chạy một đường tại một thời điểm.
